# Strepen

A strepen system written in [Laravel](https://laravel.com/) with [Livewire](https://laravel-livewire.com/) for [Scouting Die Kantanky's](https://www.diekantankys.nl/) with a [Flutter](https://flutter.dev/) based mobile application and a webview based desktop application

## Download Android app

The easiest way to download the Android app is via the [Google Play Store](https://play.google.com/store/apps/details?id=nl.plaatsoft.strepen).

If you don't want to use the Google Play store, you can always download the latest `apk` file from the [release tab](https://github.com/diekantankys/strepen/releases).
